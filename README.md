# Infinite Canvas — Miro-style Drawing App with Zoom, Pan & Undo/Redo

A minimal full-screen infinite canvas built with **Next.js 15**, **TypeScript**, and **Redux Toolkit**.  
Inspired by Miro, this app lets you draw with a white pen on a dark canvas, zoom with scroll, pan with middle-mouse drag, and undo/redo strokes.

## ✨ Features

- 🎨 Draw using white strokes on a dark infinite space
- 🔍 Zoom in/out with mouse scroll
- ✋ Pan canvas with middle mouse drag
- ↩️ Undo / Redo functionality (Redux-powered)
- 🧠 Clean Redux Toolkit state management
- 🔒 Fixed, full-screen canvas — no browser scroll
- 🧪 Tested Redux slice logic using Jest
